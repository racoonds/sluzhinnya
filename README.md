# Служіння

Простий застосунок (PWA) для обліку годин служіння, територій і нотаток. Зроблений насамперед для телефона: його можна додати на головний екран і користуватися як звичайним застосунком, зокрема без інтернету.

## Що вміє

- **Головний екран**: поточний тиждень з годинами за кожен день; по центру кільце, яке показує, скільки годин **лишилось** до цілі; скільки треба **в середньому на тиждень** і на день, щоб встигнути; чи ви випереджаєте графік, чи відстаєте.
- **Ціль**: на місяць, на службовий рік (вересень–серпень) або на свій період.
- **Таймер служіння**: запускаєте, коли виходите, і зберігаєте одним дотиком.
- **Календар**: години за кожен день місяця, деталі дня, підсумки за службовий рік.
- **Території**: номер, назва, фото карти (з масштабуванням пальцями), статус (нова / в процесі / опрацьована), дата, коли взяли, історія опрацювання, нотатки.
- **Нотатки**: з пошуком і закріпленням.
- **Нагадування**: регулярна подія для календаря телефона (`.ics`, працює на iPhone і Android), сповіщення від встановленого застосунку (Android) і підказка на головному екрані.
- **Вхід за PIN-кодом**: при першому відкритті застосунок просить придумати PIN, далі запитує його щоразу. Дані лише на телефоні; раз на місяць застосунок нагадує зберегти резервну копію (iCloud / Google Диск).
- **Акаунти (необовʼязково)**: якщо підключити Firebase, замість PIN зʼявляється вхід/реєстрація за email і паролем, а дані синхронізуються між телефонами.
- **PIN-код**, **резервна копія** у файл і відновлення з неї, темна та світла теми.

## Приватність і безпека

- Акаунти й дані зберігаються у Firebase (Auth + Firestore) вашого проєкту. Правила безпеки (`firestore.rules`) дозволяють кожному акаунту читати й змінювати лише свою папку `users/{uid}`.
- Пароль перевіряє Firebase; на телефоні зберігається лише токен сесії. Від підбору пароля захищає вбудоване обмеження спроб Firebase.
- Застосунок працює офлайн (копія даних на телефоні), а з акаунтом синхронізується у фоні: «новіша зміна перемагає», видалення теж передаються. Після виходу з акаунта дані прибираються з телефона.
- Сайт складається зі статичних файлів на GitHub Pages (через CDN), тому серверу нема чого «покласти» DDoS-атакою, а встановлений застосунок однаково працює офлайн.
- Сувора політика безпеки (Content-Security-Policy): застосунок може звертатися лише до сервісів входу та бази Firebase, не завантажує чужих скриптів (вхід зроблено прямими запитами до API, без SDK) і не відкривається всередині чужих сторінок.
- Під час збереження фото стискаються, а їхні метадані (зокрема GPS) видаляються.
- PIN зберігається лише як хеш PBKDF2-SHA256 із сіллю; після 5 помилок вмикається пауза, яка щоразу зростає.
- Користувацький текст завжди екранується перед показом.

> Важливо: оскільки дані живуть лише на телефоні, час від часу зберігайте **резервну копію** (Налаштування → Дані). На iPhone додайте застосунок на головний екран, щоб система не очистила його дані.

## Встановлення на телефон

- **iPhone**: відкрийте посилання в Safari → «Поділитися» → «На початковий екран».
- **Android**: відкрийте в Chrome → меню ⋮ → «Встановити застосунок».

## Акаунти й синхронізація (необовʼязково, ~5 хвилин)

Поки `js/config.js` порожній, застосунок працює для одного користувача: вхід за PIN-кодом, усе лише на телефоні. Якщо знадобиться вхід за email і синхронізація між телефонами:

1. [console.firebase.google.com](https://console.firebase.google.com) → **Створити проєкт** (Google Analytics можна вимкнути). Тариф Spark безкоштовний, картка не потрібна.
2. **Authentication** → **Почати** → **Sign-in method** → **Email/Password** → Увімкнути → Зберегти.
3. **Firestore Database** → **Створити базу даних** → регіон, напр. `europe-central2 (Warsaw)` → **Production mode**. Потім вкладка **Rules** → вставити вміст `firestore.rules` → **Publish**.
4. ⚙ **Project settings** → **General**: скопіювати **Project ID** і **Web API key**, вписати їх у `js/config.js` і запушити. Ці значення публічні за задумом, доступ до даних контролюють правила Firestore.

## Розробка

Без збирання й залежностей: чисті ES-модулі, HTML і CSS.

```bash
python3 -m http.server 8080
```

```bash
node --test tests/*.test.mjs
```

Наскрізний тест акаунтів і синхронізації з імітацією Firebase: `node tests/e2e/sync.cjs <тека-для-скріншотів> <будь-яке.jpg>` (потрібен Playwright).

Деплой відбувається автоматично через GitHub Actions (`.github/workflows/pages.yml`) при кожному push у `main`.
