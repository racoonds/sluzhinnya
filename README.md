# Служіння

Простий застосунок (PWA) для обліку годин служіння, територій і нотаток. Зроблений насамперед для телефона: його можна додати на головний екран і користуватися як звичайним застосунком, зокрема без інтернету.

## Що вміє

- **Головний екран**: поточний тиждень з годинами за кожен день; по центру кільце, яке показує, скільки годин **лишилось** до цілі; скільки треба **в середньому на тиждень** і на день, щоб встигнути; чи ви випереджаєте графік, чи відстаєте.
- **Ціль**: на місяць, на службовий рік (вересень–серпень) або на свій період.
- **Таймер служіння**: запускаєте, коли виходите, і зберігаєте одним дотиком.
- **Календар**: години за кожен день місяця, деталі дня, підсумки за службовий рік.
- **Території**: номер, назва, фото карти (з масштабуванням пальцями), статус (нова / в процесі / опрацьована), дата, коли взяли, історія опрацювання, нотатки.
- **Нотатки**: з пошуком і закріпленням.
- **Нагадування**: регулярна подія для календаря телефона (`.ics`, працює на iPhone і Android), сповіщення від встановленого застосунку (Android) і підказка на головному екрані.
- **Вхід через Google і синхронізація**: дані привʼязуються до вашого Google-акаунта і зʼявляються на всіх пристроях, де ви увійшли. Без входу все працює як раніше — лише на телефоні.
- **PIN-код**, **резервна копія** у файл і відновлення з неї, темна та світла теми.

## Приватність і безпека

- Без входу всі дані зберігаються **лише на пристрої** (IndexedDB). Немає спільного сервера, аналітики чи сторонніх скриптів.
- З входом через Google копія даних зберігається у **вашому власному** проєкті Firebase (Firestore). Правила безпеки (`firestore.rules`) дозволяють кожному акаунту читати й змінювати лише свою папку `users/{uid}`. Застосунок працює офлайн, а з хмарою синхронізується у фоні: при кожній зміні діє правило «новіша зміна перемагає», а видалення теж передаються.
- Сайт складається зі статичних файлів на GitHub Pages (через CDN), тому серверу нема чого «покласти» DDoS-атакою, а встановлений застосунок однаково працює офлайн.
- Сувора політика безпеки (Content-Security-Policy): застосунок може звертатися лише до сервісів входу та бази Google, не завантажує чужих скриптів (вхід зроблено прямими запитами до API, без SDK) і не відкривається всередині чужих сторінок.
- Під час збереження фото стискаються, а їхні метадані (зокрема GPS) видаляються.
- PIN зберігається лише як хеш PBKDF2-SHA256 із сіллю; після 5 помилок вмикається пауза, яка щоразу зростає.
- Користувацький текст завжди екранується перед показом.

> Важливо: оскільки дані живуть лише на телефоні, час від часу зберігайте **резервну копію** (Налаштування → Дані). На iPhone додайте застосунок на головний екран, щоб система не очистила його дані.

## Встановлення на телефон

- **iPhone**: відкрийте посилання в Safari → «Поділитися» → «На початковий екран».
- **Android**: відкрийте в Chrome → меню ⋮ → «Встановити застосунок».

## Налаштування входу через Google (одноразово)

1. [console.firebase.google.com](https://console.firebase.google.com) → **Створити проєкт** (Google Analytics можна вимкнути).
2. **Authentication** → **Почати** → **Sign-in method** → **Google** → Увімкнути, вказати email підтримки → Зберегти. Знову відкрити Google → **Web SDK configuration** → скопіювати **Web client ID**.
3. **Authentication** → **Settings** → **Authorized domains** → додати `racoonds.github.io`.
4. **Firestore Database** → **Створити базу даних** → регіон, напр. `europe-central2 (Warsaw)` → **Production mode**. Потім вкладка **Rules** → вставити вміст `firestore.rules` → **Publish**.
5. [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials) (той самий проєкт) → **Web client (auto created by Google Service)**:
   - Authorized JavaScript origins: `https://racoonds.github.io`
   - Authorized redirect URIs: `https://racoonds.github.io/sluzhinnya/`
6. Firebase → ⚙ **Project settings** → **General**: скопіювати **Project ID** і **Web API key**.
7. Вписати `apiKey`, `projectId`, `clientId` у `js/config.js` і запушити. Ці значення публічні за задумом, доступ контролюють правила Firestore.

## Розробка

Без збирання й залежностей: чисті ES-модулі, HTML і CSS.

```bash
python3 -m http.server 8080
```

```bash
node --test tests/*.test.mjs
```

Деплой відбувається автоматично через GitHub Actions (`.github/workflows/pages.yml`) при кожному push у `main`.
